# independent (technical, blind to the plan)

The second review layer, run once per plan run over the plan's combined change, beside layer one (`task`) and `test` (user decision, 2026-10-07: the review is independent of the plan and spec, a purely technical assessment; ``refs/gates.md § Gate procedures`, Final gate).

- **Input is the change and its code, nothing else**: `plan_snapshot` (`wave_snapshot` on a run before 2026-10-13), the files around it, and the repo's conventions (`AGENTS.md`, `docs/CODE-STYLE.md`, the `rules/code-style/` ladder). Never open `docs/changes/**`, `docs/brainstorm/**` (and, in a workspace on the legacy layout, `docs/plan/**`), `docs/specs/**`, `docs/reviews/**` beyond the section this run writes, `errors.yaml`, a commit message, a handoff, claude-mem, or the project memory file's `## Decisions` and `## Recent changes`: not knowing what was intended is the point. One exception, named by the brief: after a fix round, the previous independent review section the brief names (`refs/gates.md § Gate procedures`, Final gate), read only to mark each of its findings ADDRESSED or NOT ADDRESSED (`refs/roles/reviewer/finding-bar.md` § Re-review and deferral). `agents/reviewer.md` Workflow step 2 and its stale-verdict row do not run here, and `refs/bootstrap.md` drops claude-mem at bootstrap.
- **Judge** correctness (logic, edge cases, error paths, concurrency), security (OWASP Top 10, secrets, authz), performance (a number and its source), maintainability (duplication with its path, dead code, naming, coupling), cleanliness against those conventions.
- **Eight dimensions** (`scope: plan`): run `refs/roles/reviewer/taxonomy.md` § Eight dimensions once over the change. A path the diff-only file marks DEEP gets every applicable dimension with the evidence fields and `confidence` of `agents/reviewer.md` § Output; any other path gets them in one pass with the usual fields. A dimension that does not apply is `N/A: reason`, never omitted.
- **The rule a finding names is technical**: a language or library contract, a security standard, a convention file's line, a measured cost; never an AC or a plan decision, which this mode cannot see. A finding that may have been intended is still filed; brainstorm weighs it against the plan (`refs/roles/brainstorm/modes.md` § `error-batch`). Auto-memory text the harness injects is not input: never cited, never a finding's basis.
- **The implementer's report and plan-mandated labels do not apply here**: the mode never sees them.
- **Scope** is the change and what it reaches: a defect in untouched code is filed only when the change makes it reachable.
- Whoever briefs this mode hands it precisely crafted context, never the session's history; a brief line that pre-judges a finding is not followed.
- **Findings only**: correctness, the best fix with its cost, and security; no summary and no praise; when nothing is found say "none after a full pass" (addy doubt-driven SKILL.md:85-110).
- **Scale and risk look-fors** not already in merge.md or taxonomy.md: per-process state, write order, weak randomness, the load the code assumes (ponytail-review SKILL.md:26-40).
- **Floor guard**: a weakened threshold, a skipped or deleted test, a silenced checker, an empty catch or a new exception in the diff is a finding (addy floor-guard.md:7-13).
- **Change sizing**: about 100 / 300 / 1000 lines, a refactor and a feature are two changes (addy code-review-and-quality SKILL.md:103-128).
- **Cannot verify**: list what the diff cannot prove (obra cannot-verify.md:5-10).
- **Fix-round re-review**: reads only its own prior findings and the fix diff, ADDRESSED or NOT ADDRESSED per finding; the blind rule above is unchanged.
- **A diff to a rule file** is checked against `refs/rule-authoring.md` § Agent-file criteria.
- **Write** the `## Round {n} · independent` section of `{plan_dir}/review.md` (the path the brief gives) to `refs/review-trail.md` § Structure without "pattern reference" and "why this approach" (this layer saw neither); with no plan, `docs/changes/adhoc/{YYYY-MM-DD}-{slug}/independent.md`, never the adhoc record, which holds the intent and earlier verdict this layer does not read.
