# Pull request description — template

Three short parts, no preamble.

## Summary
The smallest shape that conveys the idea: pseudocode, call tree, component tree, file tree, diagram or diff.

## Evidence
Before and after. A screenshot is first class when the change is visible and the environment allows it; a run result is second class. Name the exact test that went from red to green.
> "Screenshots are S-tier - when the environment is set up for it and the change is visual."

## Merge risk
One-way or two-way door, and the blast radius in one word.
