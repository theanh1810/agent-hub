# Agent brief — template

A brief stands alone: the agent sees no conversation. Also the shape of a Lark task description (`skills/lark-task/SKILL.md`), inside its four fixed headings.

```
## Expected behaviour
<what must be true when done, observable from outside>

## Done criteria
- <checkable and exhaustive item, with the command that proves it>

## Good example
<one real, runnable case, with a note on why it is good>

## Bad example
<one case, with the six reasons it is bad>

## Stands alone
<every path, file:line, ref and prior output the agent needs; no "as discussed">
```
